## 两处刻意没搬的断言

- **`候选池` 这个词**：旧后台在自动抽取时把「规则」列标题改成「候选池」。SPA 侧改成了
  四态文案（「本期开口 3/47」/「型号只有 1 种…」/「总开关未开…」/「候选池为空」），
  比一个换名的列标题更能说明「为什么现在看起来没生效」。断言因此按四态写。
- **弹窗最小宽度 ≥1100px**：这是旧后台 `.modal` 的布局细节。SPA 改用右侧侧页
  （`--side-page-width: clamp(26rem,40vw,44rem)`），窄屏自动全屏。断言「必须 1100px」
  等于把一个已废弃的布局方案钉死在新实现上，属于反模式。侧页宽度由
  `spa_batch3` 的「不溢出视口」类断言覆盖。
