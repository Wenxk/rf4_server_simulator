# 个人中心

gateway 的 `/portal/` 提供角色资料、余额和游戏金币会员购买。同一设备先进入游戏，页面按「该来源 IP 最近一次成功登录的账号」解析角色（网关登录时写入 `kv` 的 `last_login_uid:<ip>`）；同一台机器换登录名后，个人中心跟随最近玩的那个号，没有记录时才回落到按来源 IP 分配的默认账号。

> **身份边界：** `/portal/` 只适用于单机或受信本机使用。不要直接把登录端口暴露到公网；同一 NAT、代理或出口 IP 下的用户会被识别为同一角色，可访问并消费该角色的金币。需要多人共享时应先接入独立账号认证。

会员仅使用本地游戏金币，普通、限时与永久会员状态共用主线存储方法；购买失败可重试同一订单，避免重复扣款。页面静态资源随服务提供，无需第三方图片服务。
